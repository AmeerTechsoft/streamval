# streamval

Streaming, Pydantic-backed validation for CSV, JSONL, Parquet, Arrow,
and HTTP NDJSON / SSE streams.

See [`quickstart.md`](quickstart.md) to get started, or
[`adapters.md`](adapters.md) for the per-adapter reference (including
the HTTP NDJSON adapter and the OpenAI / Anthropic SSE helpers).
